# 截图

命名：`<组合>-<语言>.png`，`zh` 为中文界面，`en` 为英文界面。

README 顶部使用 `panel-home-light-zh` / `panel-post-light-zh` / `panel-home-dark-zh`，英文版用同名的 `-en`，均为 1592×2300。

| 组合 | 文件 | 尺寸 |
| --- | --- | --- |
| 单栏：首页浅色 / 文章页 / 首页暗色 | `panel-home-light-*.png`、`panel-post-light-*.png`、`panel-home-dark-*.png` | 1592×2300 |
| 斜窗口前后叠（早期设计，未使用） | `preview-zh.png`、`preview-en.png` | 2048×1091 |
| 两栏：文章页浅色 / 暗色 | `strip-2-zh.png`、`strip-2-en.png` | 1592×1000 |
| 三栏：首页浅色 / 文章页 / 首页暗色 | `strip-3-zh.png`、`strip-3-en.png` | 2388×1150、2388×1000 |
| 2×2 网格 | `grid-4-zh.png`、`grid-4-en.png` | 1592×2000 |

`strip-3-zh` 与 `strip-3-en` 高度不同：中文版首页摘要全为 3 行、文章更长，需要 1150px 才放得下页脚；英文版是 1000px。
